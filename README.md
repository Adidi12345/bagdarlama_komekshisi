# Бағдарлама көмекшісі — Java 17

1. ZIP архивін аш.
2. IntelliJ IDEA → Open → Bagdarlama_Java қалтасын таңда.
3. Maven тәуелділіктері жүктелгенше күт. Қажет болса, Load Maven Project бас.
4. src/main/java/Main.java файлын ашып, main жанындағы жасыл ▶ батырмасын бас.
5. Төмендегі Run консоліне BotFather токенін қойып, Enter бас.
6. Telegram-да ботты ашып, /start жібер.

Токен консольге енгізіледі. BOT_TOKEN орта айнымалысын да пайдалануға болады.
Бот IntelliJ процесі жұмыс істеп тұрған кезде жауап береді.
12 тақырып, 5 сұрақтық тест, 3 практикалық тапсырма және қате түсіндірмелері бар.
Жауаптар дайын оқу материалдарынан алынады. Тест барысы жедел жадта сақталады.
